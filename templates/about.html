Project Documentation 🛠️

✨ System Overview

A sleek, modern, and fully responsive web application built using FastAPI and Python that displays top-rated books and provides personalized collaborative book recommendations.

🚀 Tech Stack

  • Backend: Python, FastAPI, Uvicorn, Jinja2
  • Data Processing: Pandas, Numpy, Pickle
  • Frontend: HTML5, CSS3 (Flexbox & Grid Layouts)

💎 Key Features

  • Top 50 Dynamic Dashboard Display
  • Vector Similarity-based Book Recommendations
  • Automatic handling for broken cover image links
  • Custom global 404 Exception Fallback Handler
